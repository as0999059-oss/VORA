# VORA

نسخة أولى من تطبيق توصيل موبايل باستخدام Expo + React Native.

## التشغيل
1. ثبّت Node.js.
2. داخل مجلد المشروع شغّل:
   npm install
   npx expo start
3. افتح التطبيق من Expo Go على Android أو استخدم Android Emulator.

## الموجود حالياً
- الصفحة الرئيسية
- البحث
- الأقسام
- المطاعم
- صفحة المطعم
- المنتجات
- السلة
- إتمام الطلب
- عنوان التوصيل
- الدفع عند الاستلام

هذه نسخة Frontend تجريبية؛ قاعدة البيانات، تسجيل الدخول، الخرائط، الدفع الإلكتروني، إشعارات الطلب، وتطبيق الكابتن تحتاج Backend وربط خدمات حقيقية.
